# Linux Training Toolkit

A personal collection of Bash tools built to learn and master
Linux from the inside — system analysis, daily habits, and
hands-on challenges.

## Scripts

### commandements
Reference guide of essential Linux commands organized by
category: navigation, processes, network, forensics, and
advanced admin. Built as a personal cheatsheet and study tool.

### rituel.sh
Interactive daily training script. Runs system checks step
by step with an integrated coach explaining what to look for
and why. Builds analyst reflexes over time.

### architect.sh
Full system scanner + challenge engine. Two modes:
- Complete scan of kernel, resources, processes, network,
  users, logs, and recent changes
- Challenge mode: 75+ practical exercises across 5 categories
  (System, Network, SOC, Red Team, Forensics)

## Purpose
These tools were built for self-training toward SOC Analyst
and DFIR roles. The goal: understand Linux deeply before
relying on automated tools.

## Usage
```bash
bash rituel.sh
bash architect.sh
```
